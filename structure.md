# SYNC_NODE Project Structure

## Overview
SYNC_NODE is a full-stack AI workflow platform for document ingestion, extraction, semantic search, and automation orchestration.

It combines:
- a FastAPI backend for APIs, data processing, and AI services
- a PostgreSQL + pgvector database for structured and vector-based storage
- a React + Vite frontend for user interaction and monitoring
- Docker Compose for local orchestration and service management

## Core Modules

- Backend API: handles ingestion, search, document lifecycle, and workflow orchestration.
- AI Services: integrates with Gemini for classification, extraction, and summarization.
- Vector Search: chunks content and stores embeddings using pgvector for retrieval.
- Frontend UI: provides a document dashboard, search experience, and workflow monitoring.
- Deployment: uses Docker Compose to run app services together locally or in containers.

---

## Purpose
This repository is designed to demonstrate an AI-powered operations pipeline that can ingest unstructured business data, extract structured insight, and answer queries with grounded retrieval-based responses.
